# Portfolio de Yasser Belouanas

UX/UI designer en formation, étudiant en BUT MMI à l'IUT de Haguenau.

Le site est en ligne ici : https://ybelouanas2-debug.github.io

- `index.html` : tout le site (accueil et études de cas)
- `fonts/` : les deux polices du site, Archivo et Instrument Sans, chargées à part pour que la page arrive plus vite
- `404.html` : la page affichée pour une adresse qui n'existe pas
- `cv-yasser-belouanas.pdf` : le CV, téléchargeable depuis la partie contact
- `img/` : les captures des maquettes, du site Découvrir Kyoto et des projets courts (flyer, infographie, site Hunter x Hunter, vidéo). Les visages et les contacts sont floutés. `og.png` est l'image qui s'affiche quand on partage le lien.
